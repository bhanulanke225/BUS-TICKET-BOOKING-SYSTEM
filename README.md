A Bus Ticket Booking System is a simple application developed using the C programming language that allows users to book bus tickets, view available routes, check ticket fares, and cancel their bookings. The system provides a menu-driven interface through which users can select their preferred route, enter the number of seats required, and book tickets based on seat availability.

The system maintains information about different bus routes, ticket prices, available seats, and booking IDs. Each booking is assigned a unique ID, which can be used to identify and cancel a reservation. It also updates the available seat count whenever tickets are booked or cancelled, helping to prevent overbooking.

The project uses concepts such as arrays, loops, conditional statements, functions, and basic data management in C. It demonstrates how programming concepts can be applied to a real-world transportation system to make the ticket booking process more organized, efficient, and user-friendly.

Main features:
- View available bus routes.
- Check ticket prices.
- Book tickets according to seat availability.
- Generate a booking ID.
- Cancel tickets using the booking ID.
- Update the number of available seats.
- Display booking details.
This project is designed to demonstrate the fundamentals of C programming while simulating a real-world bus reservation system.# BUS-TICKET-BOOKING-SYSTEM
